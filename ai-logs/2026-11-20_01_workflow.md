## 4. What I did and why
- **Backend:** `internal/server` builds one `net/http` router. It answers `GET /api/health` with 200 and `{"status":"ok"}`. Other methods on that path get a JSON 405, and any other `/api/...` path gets a JSON 404.
- **Entry points:** `api/index.go` and `cmd/local/main.go` both just call `NewRouter()`. So local and Vercel run identical logic, and `api/index.go` stays the only Go file in `/api`.
- **Vercel config:** `vercel.json` sets `framework: vite` and region `fra1`. The `/api/(.*)` rewrite comes before the SPA fallback to `/index.html`.
- **Frontend:** `App.tsx` calls `/api/health` on load and shows "API: ok" or "API: error". Vite proxies `/api` to `:8080`.
